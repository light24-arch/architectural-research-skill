# 项目类型：研究侧重点与设计转译

项目类型确认后，安排研究问题、案例阅读、备选方向或交付检查时读取。
类型确认与交付选择遵循 [SKILL.md](../SKILL.md)，任务范围遵循 [task-modes.md](task-modes.md)，
证据标准遵循 [evidence-quality.md](evidence-quality.md)。本文件是三类侧重点的唯一维护位置。

## 1. 共通基础与适用顺序

三类均以任务书、场地、人群、环境及可追溯案例支撑设计判断。类型调整问题优先级、分析深度和验证方式，
不改变事实/推断/待核实标准，不按类型降低证据质量，也不强制增加章节、案例数量或固定篇幅比例。
采用“共同研究基础 + 类型侧重点 + 任务书具体要求”；用户明确目标及任务书中的具体要求校正类型的初步排序。
不把课程设计等同于只谈形式、实际项目等同于排除探索、竞赛等同于只做概念或效果图。

读取任务书后，在项目概况/工作摘要说明：已确认类型、当前阶段或目标、本次优先研究问题、关键缺口。
课程教学目标、实际项目阶段、竞赛性质与评审标准等先从材料提取；已有信息不重复询问。
只有缺项会改变研究范围或关键判断时再简短提问，其余标注缺口并继续共通工作。
项目类型与建筑功能类型、完整研究/专题/案例库/补充模式分别记录；专题和补充只应用有关的侧重点。

## 2. 课程设计：问题形成 → 空间推演 → 设计论证

核心目标：建立有依据的设计问题，支持空间思考和设计方法；解释为什么选这个方向以及如何验证。

| 优先问题 | 研究与转译重点 |
|---|---|
| 课程主要训练什么能力？ | 提取教学目标、当前评图阶段和成果要求；据此选择场地、类型、公共空间、更新或技术整合的研究深度 |
| 场地为什么需要拟议建筑？ | 对允许自主策划的任务，论证服务对象、真实或假设需求与功能组合；功能已指定时研究其空间关系，不擅自改题 |
| 案例提供什么空间方法？ | 深读平面、剖面、动线、尺度、空间序列与场地关系，提炼可迁移的方法及差异 |
| 下一步用什么推演检验？ | 对候选方向明确需要比较的空间变量，提出草图、模型、同尺度布局或剖面对比，并说明结果影响的选择 |

转译重点：每个方向说明“值得探索什么、用哪些空间推演检验”。方向比较关注问题依据、组织差异、
取舍和论证路径；技术整合或真实性要求由课程任务决定，不因课程类型省略。
完成判断：在所选任务范围内，教学/任务目标、调研发现、空间回应与下一步推演有清楚对应。
尚未执行的草图、模型或验证列为计划，不把前期研究描述成已完成设计训练或已通过评图。

## 3. 实际项目：真实需求 → 可行性 → 实施与使用

核心目标：明确需求、实施边界和关键风险，支持判断哪些方向值得推进以及成立条件。

| 优先问题 | 研究与转译重点 |
|---|---|
| 各方需求是否可靠、是否冲突？ | 区分业主愿望、使用者需求与运营要求，记录已确认/待调查内容；识别优先目标及冲突 |
| 哪些场地和建设条件会改变方向？ | 优先核实用地、既有建筑状况、交通接入、基础设施和适用规划要求；未知条件不能作为已满足的硬约束 |
| 投入与实施条件是否支持？ | 按当前阶段研究预算、周期、施工条件及分期可能；估算明确依据和假设，前期聚焦可行性及风险识别 |
| 建成后如何使用与管理？ | 按需研究管理、维护、使用时段、空间转换、长期适应性，以及设计方向所依赖的运营主体与资源 |

转译重点：每个方向说明“解决哪些需求、在什么条件下成立、有哪些代价、推进前需核实什么”。
比较需求满足、条件依赖、实施/运营取舍和最大不确定性；预算或技术资料不足时保留缺口。
完成判断：关键需求和边界可追溯，各方向的推进条件及优先核实事项清楚，深度符合当前项目阶段。
前期研究不自动扩成施工深化、完整造价或审批结论；技术及适用要求按项目所在地与阶段核验。

## 4. 竞赛作品：命题回应 → 独特贡献 → 空间与表达的一致性

核心目标：回应命题，形成有辨识度且完整的主张，说明独特贡献并以证据和空间回应证明。

| 优先问题 | 研究与转译重点 |
|---|---|
| 竞赛公开要求是什么？ | 提取主题、公开评审标准、硬性条件、提交要求与期限；不凭印象猜测评委偏好 |
| 什么切入点有依据且有区别？ | 从场地矛盾、使用需求或已有解决方式的不足形成主张；比较相关案例，不能仅以造型新奇或概念命名证明贡献 |
| 主张如何改变空间和使用？ | 分析功能、组织、环境或使用体验的具体变化，指出适用条件和关键验证问题；预期效果不写成实测成果 |
| 如何清楚展示论证？ | 筛选支撑主张的发现，组织“问题—依据—空间动作—预期效果”的表达链，提出与提交要求有关的图示计划并保留来源 |

读取材料区分概念竞赛与实施型竞赛。实施型竞赛叠加实际项目中有关的可行性、实施与运营分析，
以具体竞赛要求决定深度；概念竞赛同样保留成立条件及证据边界。性质不明时注明，先推进共通研究，
只有其影响关键研究范围或判断时再询问，不自行归为纯概念竞赛。
转译重点：每个方向说明“如何回应命题、贡献何在、用什么证据和图示证明”。
完成判断：公开要求有对应，主张、依据与空间回应一致，关键分析和表达任务可操作；不承诺获奖或虚构排名。

## 5. 案例、方向与成果中的应用

案例仍按 [precedent-matching.md](precedent-matching.md) 的“经典大师 → 近年同类型 → 其他专项”顺序，
计数与停止条件不因项目类型改变。课程侧重空间方法，实际项目加强近期建成案例的使用和实施资料，
竞赛侧重设计主张如何形成并落实；资料缺失按证据规则标明，不由照片推定运营或建造效果。

各方向沿用 [design-directions.md](design-directions.md) 的六项内容与逐问题分析表，
将对应类型的转译重点融入“重点问题与分析计划、成立条件、优先验证与选择依据”，不新增重复模板。
报告沿用 [report-structure.md](report-structure.md) 的九模块：01 说明研究重点；07 落实方向与分析；
08 体现案例阅读重点；09 给出符合项目类型的取舍与下一步。主文档形式及 HTML 选择不由类型决定。

课程兼参赛、实施型竞赛等交叉用途可组合相关侧重点，说明主目标与叠加要求，复用共通证据与分析。
主目标不明且影响取舍时询问；不擅自取消已确认用途，不叠加三套完整清单。
用户修改类型或阶段时仅调整受影响的问题排序、分析深度和转译要求，保留有效成果。

## 6. 方法参考的边界

以下资料为侧重点设计的参考，不是中国课程评分规则、本地法定要求或每项竞赛的统一标准：

- [NAAB 建筑教育认证说明](https://www.naab.org/accreditation/accreditation-faqs)：学生作品需呈现综合信息并作出设计决策的能力；本项目教学目标仍以课程文件为准。
- [RIBA 项目工作流程](https://www.riba.org/work/insights-and-resources/riba-plan-of-work/)：按阶段组织项目任务并考虑成本、使用及可持续性；本项目实施要求仍需当地核验。
- [UIA 建筑竞赛指南](https://www.uia-architectes.org/wp-content/uploads/2022/02/2_UIA_competition_guide_2020.pdf)：评价标准应对应任务与要求；以具体竞赛正式文件和公开答疑为准。
