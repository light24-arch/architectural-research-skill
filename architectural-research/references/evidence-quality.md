# 证据质量与来源核验

适用于全部任务模式和输出格式。按“具体结论”判断状态，不能因为某来源权威就把整章标为事实。

## 1. 三种状态

| 状态 | 何时使用 | 表述要求 |
|---|---|---|
| 事实（来源已核验） | 读取了可定位的材料，能直接支持这一说法 | 紧邻来源编号；区分用户材料记载、机构发布、作者宣称、实测和图纸观察 |
| 推断 | 从事实、代理数据、计算或设计经验得出的判断 | 写“基于…推断/初步测算/拟探索”，给依据、假设、适用边界和验证动作 |
| 待核实 | 关键原始材料缺失、只见摘要、来源冲突或不能确认适用性 | 保留缺口/候选值与核实路径，不当作已确认硬约束或核心对标依据 |

来源已核验表示材料与该说法相符，不表示该说法已获独立验证。
例如“事务所称项目促进交流”是可归属的宣传陈述，不能改成“项目已显著改善社区关系”。
“任务书记载限高 24m”可以归属为任务书事实，规划法定限高仍需适用文件核验。
设计建议是推断/方案主张；效果是预期，不包装成项目现状事实。

## 2. 来源记录的最小字段

关键证据用 E01、E02…；已有成果有稳定编号时沿用。可以共用一个来源支持多条结论，但定位分别记录。

| 字段 | 内容 |
|---|---|
| ID 与关联结论 | 编号、支持哪条信息/策略，不笼统写“全文来源” |
| 标题及发布主体 | 文件/网页/数据集名；作者、机构或提供者 |
| 地址与定位 | 实际发现的 URL，或本地文件名/版本；页码、条款、图号、表行或网页段落标题 |
| 时间 | 发布/更新日期（不详即注明）、访问/核验日期；数据统计期单列 |
| 来源类型 | 用户任务书、官方文件、研究论文、事务所说明、媒体、图像观察、模型/API 等 |
| 核验状态 | 内容已读且支持结论 / 仅摘要或元数据 / 不可访问 / 待核验 / 存在冲突 |
| 范围与限制 | 地区、版本、对象、计量口径、代理关系及利益关联等影响结论的限制 |

短专题可在正文注释中记录，不强制另建台账文件。完整报告附来源表，案例卡保留相关来源与未知项。
引用靠近结论；表格混有多个状态时逐行或逐字段标注，不能一句“仅供参考”覆盖所有数字。

## 3. 核验流程

1. 通过检索、用户材料、已打开页面或实际 API 返回获取真实地址，不凭记忆生成 URL。
2. 打开并阅读相关内容，核对项目/主体、年份、指标单位和断言；搜索结果命中不等于结论验证。
3. 留可查定位。只读摘要时写“摘要显示…（全文未读）”；不引用未读全文里的细节。
4. 高影响、时效敏感或相互矛盾的信息，查原始/最新适用材料；政策确认辖区、版本、条款和适用对象。
5. 同一事实存在矛盾时并列来源和口径差异，不平均处理。可由阶段/口径解释则写明；无法解释标待核实。
6. 稳定旧证据可沿用已记录的核验日期与定位；用户要求更新、内容敏感或链接失效时重新查验。

网页不可读时，真实发现的链接可列为“待核实来源/检索线索”。摘要仅支持摘要中实际可见的内容，
不能作不可见图纸、精确测量或关键合规结论的证明。不要把无关“相关报道”写成出处。
交叉证据按来源独立性判断；多家转载同一事务所稿件仍是一条来源链。

## 4. 数据与图像边界

- 数据记录采集/统计时间、地点、尺度、单位、方法和缺测。未披露时留空并说明，不猜测元数据。
- 年均温与夏季极值、计容面积与总面积、建成年与发表年、直线距与步行距不能互换。
- 换算/测算列公式和输入来源；假设输入使结果成为条件性推断，不因算术准确提升为实测事实。
- 照片/图纸观察支持可见空间关系；方向、尺度无标注时不精确测量，不推断实际运营与使用效果。
- 遥感、示意、AI生成、模板占位、现场实拍分别标明。摄影/图纸署名和来源页不能随意省略。
- 风玫瑰仅以频率统计生成；没有频率只画季节风向示意，不虚构比例。
- 内置气候库缺少逐项来源、站点和期段时，视为待核实线索；邻城代理是推断，气候区推断限于定性。

## 5. 简洁示例

- 事实（用户材料）：任务书 v2 第 3 页要求 100 间客房。[E01] 尚未核验规划许可条件。
- 推断：按每间暂取 35㎡估算客房使用面积约 3500㎡；未含交通及公共空间，待功能表验证。[E01]
- 待核实：资料分别称面积 6200㎡与 7800㎡，计容/总面积口径均未披露；保留两值并查询图纸指标表。[E02/E03]
- 推断：照片显示连续半室外廊道，可探索串联公共节点；日常是否对公众开放需运营资料核验。[E04，图 6]

交付时只声明实际完成的核验程度，不写“所有来源均已验证”覆盖不可读页面或代理数据。

## 6. 历史过程与平台材料

- 发展史分别记录计划发布、程序启动、实际施工／搬迁、阶段完成及当前状态；有计划不等于从当年连续实施。
- 同一地点的不同阶段、地块和对象不拼成一条确定沿革；不由上传年份、文章编号或建筑大小给房屋定年。
- 新闻中的“清零”“开业”“提升”等按原对象解释，不自动扩大为拆除完成、永久开放或长期成效。
- Citywalk和生活平台资料记录作者／机构、发布时间、节点顺序、实际可读部分；区分已发布路线、个人行程和研究者拟议串联。
- 平台原帖未读到时说明限制，可用相关网站补证但不称为已核验该平台热门路线；不编造点赞、收藏和热度。
- 搜索遇同名街道或市场，按城市与节点排除混入对象。路线中外围节点不等于设计核心，不用沿线客流推算核心容量。
