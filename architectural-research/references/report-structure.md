# 报告内容结构（唯一维护位置）

完整研究、策略生成或完整报告渲染时读取。专题和补充只在需要相应内容结构时读取。
范围由 SKILL.md 与 task-modes.md 决定；证据遵循 evidence-quality.md；此文件统一编号、数量和策略要素。

## 数量与对应关系


- 用户指定数量优先。未指定时，完整研究以 5–8 条策略为参考目标，按主要问题覆盖和证据充分程度调整。
- 不为凑数重复策略或补造依据；数量不足说明具体缺口。专题、案例库、补充任务不套用此目标。
- 挑战、机会、案例、画像、图片、结论数量均由相关性决定，不固定为 4、5 或 6。
- 机会注明关联挑战；可一对多或多对一。编号、分母、锚点和对照表随实际数量生成。
- 策略矩阵的问题来源有四类、空间类型有五类，为 4×5；可按问题增减维度并同步表头。

## 完整报告九模块


| 编号 | 名称 | 范围 |
|---|---|---|
| 01 | 项目概况 | 已确认项目类型、当前阶段/目标、优先研究问题、任务书、指标简表、约束与信息状态 |
| 02 | 背景分析 | 城市/区域语境、类型背景、定位及相关规划 |
| 03 | 场地与环境 | 地块与邻建、交通、气候、风险；按需功能与体量深化 |
| 04 | 人群与文化 | 用户行为、历史文化、空间需求与假设 |
| 05 | 设计挑战 | 有证据支持的主要问题及关联证据 |
| 06 | 设计机会 | 关联挑战、可能价值及成立条件 |
| 07 | 策略探索 | 备选方向、重点问题与分析计划；关联八要素策略、覆盖与互斥条件 |
| 08 | 案例对标 | 匹配、图纸/图片、比较、迁移边界及来源状态 |
| 09 | 结论与建议 | 可操作发现、方向取舍、硬性/弹性/待核实条件与优先验证 |

该编号用于所有新完整报告。现有补充任务保留原结构，以章节名映射，不强制重编号。
无法研究的相关内容简述原因与补充动作，不为填充九模块增加无关信息。
来源目录与证据记录可作附录，不额外增加强制研究模块。

类型侧重唯一遵循 [project-types.md](project-types.md)：01 说明研究安排，07 落实到方向与分析，
08 落实到案例阅读重点，09 给出相应取舍与下一步；不增加第十模块、类型固定篇幅或降低证据要求。

### 调研到设计的转译位置

07 先呈现数个备选设计方向及各自的重点问题、后续分析计划，再按方向关联八要素策略；
09 比较方向的取舍与优先验证事项。详细方向生成及表达规则唯一遵循 [design-directions.md](design-directions.md)。
方向不等于策略数量；总策略量遵循本文件，不按每个方向重复生成 5–8 条。
不额外增加强制第十模块，档案文件划分不由此确定。

## 策略卡唯一八要素

标题为“策略 NN：名称”；编号是元信息，不占八要素。HTML、Word、Markdown、飞书统一如下：

1. **核心问题 Problem**：来自 05 的具体挑战及不处理的影响。
2. **设计依据 Evidence**：关联 01–04 的事实/推断和来源编号；缺项不造依据。
3. **设计机会 Opportunity**：关联 06，说明成立条件。
4. **设计概念 Concept**：简明方向及与本项目的关系。
5. **空间动作 Spatial Operation**：与问题匹配的具体操作，如边界开放、体量错动、半室外过渡；
   通常 3–5 个有效动作，不为满足数量拆分同义词。说明位置、对象和关系。
6. **参考案例 Reference**：来自 08 或已核验新增案例；说明学什么、需调整什么。
   无可靠案例时明确缺口，将其作为待验证策略，不补造案例。
7. **适用条件 Applicability**：尺度、气候、资源、产权/运营及前置约束；未知项注明。
8. **策略价值 Value**：预期解决什么、代价/局限、下一步如何验证；未经评估不写收益百分比。

问题来源 × 空间类型可辅助发散：场地/人群/文化/环境 × 开放/聚落/生态/体验/未来。
它是启发工具，不是强制覆盖全部二十格的任务。
