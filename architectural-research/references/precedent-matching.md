# 类似案例的匹配与分析

规则来源：任务范围遵循 [SKILL.md](../SKILL.md)；章节、数量和策略结构遵循 [report-structure.md](report-structure.md)；证据遵循 [evidence-quality.md](evidence-quality.md)。排版不改变研究范围。
## 1. 搜索前建立匹配依据

先读任务书和用户提供的案例。记录：设计问题、服务对象、介入尺度、不可忽略的约束，
以及每个原案例的特点。保留“共同特点”和“独特参考方向”，不要把多个案例压成一个泛化标签。
用户没有原案例时，直接从任务书的设计问题建立依据，不虚构原型。

已确认项目类型时，按 [project-types.md](project-types.md) 的“案例、方向与成果中的应用”选择阅读重点和所需资料，
将其落实到入选理由、比较维度及迁移条件；不改变下述三阶段检索顺序、数量与停止条件。

用下面的维度选出本任务最相关的 3–6 项，说明哪些属于核心条件、哪些只是补充：

| 维度 | 要比较什么 |
|---|---|
| 场地与既有条件 | 历史街区、城中村、工业园区、校园、基础设施；保留哪些已有结构或生活 |
| 介入尺度与阶段 | 单房间、院落、单体、街巷、片区；一次改造还是渐进实施 |
| 人群与问题 | 谁使用、谁受益、谁可能受影响；改善了什么具体矛盾 |
| 空间动作 | 边界开放、院落连接、设施植入、可逆构造、垂直共享等如何发生 |
| 实施与运营 | 参与主体、产权条件、公共服务、使用时段、维护和运营责任 |
| 文化与环境 | 记忆、地域空间、气候与材料条件是否影响可迁移性 |

“城市更新”“公共性”“文化激活”等宽泛词不足以单独构成入选理由。
若资料未披露产权或运营，不将其视为已经匹配；写“信息不足”。

## 2. 用户偏好的三阶段案例检索

默认按以下顺序发现、筛选并组织案例；用户本次指定的时期、地区、项目、数量或“只找某类”优先。
先建立任务书匹配条件，再找经典，不能跳过任务理解直接列大师名作。

| 阶段 | 优先对象 | 研究作用与取证重点 |
|---|---|---|
| 1 · 经典大师作品 | 优先选 1–2 个业界经典、与任务书项目相近的大师作品 | 建立类型与空间组织的参照；重点读平面、剖面、流线、空间序列与场地关系 |
| 2 · 近年同类型项目 | 近些年已建成且资料较丰富的同类型项目 | 补充当代使用需求、技术与实施方式；核实建成时间并取得可分析的图纸、照片和项目说明 |
| 3 · 其他专项参考 | 前两阶段后，按尚未覆盖的问题扩展到其他类型、时期或方向 | 补足具体空间动作、环境回应或运营思路；明确为什么跨类型参考及不能直接迁移的部分 |

### 第一阶段：经典与大师如何判断

- 从项目的主要用途、服务对象、规模/介入尺度、空间组织与场地问题寻找相近作品。
  “类似任务书项目”不等于只要同一建筑类型；关键差异需说明。
- “大师”与“经典”称谓需有可追溯依据，如专业机构/建筑档案、权威专著、教学研究或有实质分析的专业评论。
  不把建筑师获奖自动等同于其每个项目都是经典，也不凭模型记忆或榜单赋予称谓。
- 优先能够读到图纸及空间分析的代表作；只有外观照片时记录资料不足，不写未经支持的空间机制。
- 1–2 个是优先目标，计入总案例数，不额外扩大用户要求的数量。总数只要 1 个时先选最匹配的经典。
  找不到可靠、相近的经典时说明缺口，继续第二阶段，不用无关名作或虚构大师标签凑数。

### 第二阶段：近年与资料丰富如何判断

- 用户指定年限时使用指定年限；未指定时先以研究当年向前约十年为检索窗口，简述此口径，
  不另开确认轮。不足时可扩大并说明；窗口随研究日期变化，不写死某组年份。
- “近年完成”以建成/竣工时间判断，区别于设计、获奖、改造或网页发表年份。未确认建成状态的
  候选不能归为已建成；未建成方案只有在用户要求或明确专项用途时另列。
- 资料丰富以能否回答设计问题判断，优先有项目基本信息、相关平面/剖面、实景及设计说明。
  不用图片总数或转发数量代替资料质量；关键运营、技术和性能信息仍需对应证据。
- 在匹配度相近时优先资料完整、可读图、来源清楚的项目；不按单一建筑师名气排序。

### 第三阶段与停止条件

- 先完成前两类的有限筛选，再根据比较矩阵中的问题缺口补找其他项目，不在初始阶段泛搜大量跨类型作品。
- 若前两类已覆盖用户数量和核心问题，可以停止，不为凑齐三类新增案例。用户明确要求三类时，
  在总数量内安排三类；受数量或资料限制无法满足时说明。
- 补充已有案例库时先确认已有经典/近年案例与未覆盖问题，保留已有文件；无需每次重复新增 1–2 个经典。

### 查询与来源

每一阶段均把类型、核心问题、空间动作、场地条件组合成中英文查询，地区、时期和建筑师作为阶段过滤条件。
例如经典阶段用“图书馆 + 空间组织 + 经典作品”，近年阶段用“图书馆 + 建成 + 平面/剖面 + 时间窗口”，
专项阶段针对仍缺少的公共边界/流线等问题检索。以上是查询示例，不是已核验案例。
建筑档案、专著或机构资料可补充经典研究，事务所、业主、专业媒体和研究资料可补充近年项目；
来源渠道不改变三阶段项目顺序。所有来源遵循 evidence-quality.md。

## 3. 核验、筛选和停止条件

为候选项目维护简短记录：名称/地区、经典/近年同类/其他专项类别、设计者、建成时间及核验状态、来源、
可用图纸/资料、匹配维度、主要差异、资料缺口、入选或排除理由。
候选表是研究过程资料；最终只保留有用的筛选依据和结果，不输出无关内部过程。

- **核心对标**：有来源支持核心问题及至少两个相关比较维度；差异不妨碍其参考作用。
- **专项补充**：只对某个空间动作或运营方式有启发；说明专项用途和整体差异。
- **不入选/待核验**：仅名称或类型相似、核心事实无法确认，或所需条件与本项目相冲突。

这些等级是定性判断，不是未经校准的评分算法。不要把“未知”当成“符合”，也不要把资料缺失
当成项目一定没有相应机制。需要地区覆盖时以资料可靠为前提；若无法满足，说明缺口，不凑数。
当用户要求的数量/地区已覆盖，或主要维度已有足够且不重复的对标时，按三阶段停止规则完成分析。
“经典/近年/其他”是检索与展示类别，“核心对标/专项补充/待核验”是参考作用与核验状态，两者分开记录。

## 4. 每个入选案例必须回答

1. **为什么入选**：说明检索类别及参考作用，对应哪条任务书要求或哪个原案例；明确具体匹配维度。
2. **解决什么问题**：场地、人群及原有矛盾；不要只复述建筑概念。
3. **如何通过空间实现**：列出能从文字、照片或图纸中得到支持的具体动作。
4. **依赖哪些实施条件**：规模、阶段、参与主体、产权或运营；未知项注明。
5. **能学什么**：把动作转成当前设计可以检验的做法；沿用用户分析框架。
6. **不能直接学什么**：尺度、气候、制度、资源和人群差异；说明需调整、仅供思路或不适用。

比较矩阵使用共同维度。每个案例无须在所有维度都相似；专项补充案例标明其角色。
与多个原案例对应时分别说明，不把所有参考项目统称为“同类”。
新案例成果默认按“经典大师 → 近年同类型 → 其他专项”展示，可在现有索引增加分组或字段；
用户已有组织方式优先，不强制重命名旧案例、移动文件或更改已确认框架。

## 5. 示例：三个更新案例如何保留差异

假设用户提供的材料分别强调院落微更新、历史层积与城村共生、园区开放及持续运营：

- 院落方向重点比较居民生活、局部改善和渐进实施。
- 城村共生方向重点比较新旧叠加、连接方式和复杂边界。
- 园区方向重点比较路径开放、建筑再用与运营组织。

某个小型社区空间可能是院落方向的核心对标，却只对园区方向提供公共界面启发。
大型文化园区即使外观接近，也未必适合小尺度居民院落；应标为专项补充并说明差异。
上述仅是匹配方法示例；具体原案例特点以实际用户文件和核验资料为准。

## 6. 详细研究：说明实际读到了哪一层

用户要求详细研究时，先确定要解决的建筑问题与可用资料，不以篇幅或图注清单代替原图分析。
以下是不同证据能力，不是必须全部达到的统一评级：

| 实际资料／工作 | 可以交付 | 仍不能宣称 |
|---|---|---|
| 项目正文、机构记录、可靠基本信息 | 文字机制研究、空间关系假设、使用与管理条件 | 已逐图读懂平剖面、测得尺度或验证使用效果 |
| 已查看可辨认照片／图纸 | 指向具体图号的入口、边界、空间序列观察 | 图上没有尺寸的精确测量；照片之外的产权和运营 |
| 取得可读尺寸与可靠平剖面并完成分析 | 注明口径的尺度、路径和剖面对比 | 原图等同现状测绘、比较方案已经实测有效 |
| 取得有方法、时段和对象的后评估／现场记录 | 对应范围内的使用与变化判断 | 全项目或长期效果，不超出调查覆盖 |

### 读图要落实到建筑关系

按当前问题选少量关键图，并记原图名／作者／来源、观察、推断与未知项。
优先看平面中的进入、通行、停留、后台和公共／私人边界，以及剖面的高差、遮蔽、视线与气候。
需要讨论建造时再读材料、支撑、连接、排水和替换维护；不从照片猜出完整受力、设备或工程尺寸。
只有图纸标题而没有成功查看图像时，列为“图纸入口待读取”，不写成已经完成原图分析。

### 图纸取证和降级

- 先尝试设计方／业主原页面或已发现的可靠图集；失败时换可读来源，不连续调用同一失效地址和同一路径。
- 页面与图片分别记录成功程度；原文读到不代表图片已验证，HTTP成功不代表图片内容属于正确项目。
- 不猜造图片URL、重画不可见原图或用其他项目照片替代。访问限制明确时保留来源页，已有结果仍交付。
- 关键图仍不可读时，明确成果是文字机制研究；关系示意标无比例，尺寸、细部和图纸深化待补。
  若用户明确要求必须完成原图对比，未取得图纸就是未完成项，不能用更长文字宣称已完成全部要求。
- 同一稿件的多站转载只是一条来源链。稳定旧证据可沿用原核验记录，本次失败也要注明；不冒充本次重新读取成功。

### 将研究组织成下一步空间比较

详细案例至少围绕一个本地问题给出具体动作、迁移前提和检验方法。按需要比较两种有差异的组织，
例如沿街停留／独立院口、外围接续／局部贯通；不固定要求每案增加一整套策略卡。
有尺寸才同尺度比较，没有尺寸先作关系分析。不同面积、阶段和作者的范围分别记录，不能用原案规模反推基地容量。

入库授权、文件清单及同步方法见[research-maintenance.md](research-maintenance.md)。
