# 连续研究、定位与案例库维护

用于用户纠正位置、筛选已有案例、先看候选再决定、指定入库或要求结合最新调研完善关联时。
证据状态遵循[evidence-quality.md](evidence-quality.md)，案例研究遵循[precedent-matching.md](precedent-matching.md)。

## 1. 先核准研究对象

- 场地简称、课程命名与行政地名可能不同；不由一个相似名称直接认定社区、学校或河道。
- 有地图、任务图或用户位置补充时，先对照可识别地标、街巷和邻接关系，再查对应资料。
  至少交代哪项材料支持位置、哪些要素可相互核对；不能核实时保留暂定位置。
- 用户图是定位输入；正式红线、产权、现用功能及保护条件另查。图上开敞不等于闲置，POI不证明当前营业。
- 图片的提供、上传、拍摄及地图更新日期分别记录；没有北箭头、比例尺或明确边界时不推造测量。
- 位置存在会改变研究对象的歧义，问一个关键问题，同时整理不依赖该位置的材料；不继续积累可能属于另一地块的结论。

## 2. 更正要传播到依赖结论

按实际影响检查：定位 → 周边资源／人群 → 证据适用性 → 问题判断 → 设计方向 → 案例关联与踏勘路线。
不强制另建数据库；在已有来源表或相关笔记里记清“原判断、为何撤回、新依据、影响范围”。

- 修订受影响段落，不只在报告末尾追加免责声明。原证据可以保留追溯，但标明不再支持当前对象。
- 撤回由错误前提推导的需求、尺度和功能；共享气候背景等仍有效内容不必重做。
- 保留任务书原文、原图及用户批注；用户补充与研究者说明明确标注，不伪装成原任务书条文或法定条件。
- 重大更正同步总览、比较矩阵、方向和现场计划中有关部分；只改必要文件，不重生成整库。

## 3. 用户筛选后，以当前文件为准

开始修改及提交前各盘点一次实际文件。区分案例卡、索引／比较／来源笔记、候选记录和历史附件；
统计依据沿用用户结构，不把任意Markdown文件都算成案例，也不把历史总数当成现状。

- 以本轮已读取的真实清单建立链接；文件已移除时撤下当前推荐，不擅自恢复或删除历史附件。
- 操作期间清单变化，重算受影响数量和链接，再继续；不要因某文件缺失，把它重新创建成用户未选择的项目。
- 原编号可保留不连续，新编号避开已用／历史编号，避免破坏来源引用。
- 已有笔记增量修改，保留用户高亮与手工内容；整段重编前确认其中没有需保留的批注。
- 使用当前目录中的索引与表格，不因本技能的示例路径把文件写到另一知识库。

## 4. 候选、已选择和正式入库分开

| 用户要求 | 本轮应完成 | 后续条件 |
| --- | --- | --- |
| “先给初步信息，我决定是否加入” | 有限候选：基本信息、匹配问题、资料可读性、差异和推荐依据 | 不建正式单案卡，不计入正式数量 |
| “把这个案例详细研究并加入” | 按已选范围深读、单案卡、索引／矩阵／来源与课题关联同步 | 已授权，直接完成，不重复问是否入库 |
| “筛选后继续完善关联” | 读取当前保留案例，关联最新场地问题与可检验空间动作 | 新发现另作候选，不自动填补被删案例 |

候选用临时编号或状态即可，不强制新增字段、文件夹或每候选一篇。
选择后的初筛记录可保留，明确已转入哪个正式案例；其余候选继续待选，不把整份候选清单说成全部待选或全部入库。

## 5. 关联应使下一步设计更明确

沿用既有问题编号，写清：本地依据／假设 → 案例中已知动作 → 可迁移条件 → 要比较的平面、剖面或时段 → 什么证据会改变选择。

- 不把案例中的食堂、校园、共享花园等反推为基地既有或必需功能。
- 对已有服务先查位置、时段、资格、容量与路径空缺；有不足才论证新增，必要时只延伸路径或服务时段。
- 市井生活转译到买菜、置物、停留、回家、清洗、收摊、养护等具体活动，并纳入后勤、收纳和维护。
- 跨类型借鉴只覆盖相应动作；例如文化节点的后台分区不证明花卉保鲜技术，园区公共路径不证明住宅通行权。
- 未做的访谈、计数、同尺度重绘、模型和测试称为计划，不因文字关系表完整而宣称设计已验证。

## 6. 提交前的维护检查

核对实际案例数、重复编号、候选状态、索引／矩阵／正文链接和用户批注；涉及数量变化时同步相关总览。
检查结果与研究质量分开：链接通过不证明来源支持结论，元信息通过不证明图纸读懂。

Markdown库可按需运行只读工具：

```text
python scripts/check_library.py --library "案例目录" --project-root "项目根目录"
```

工具默认排除00—03四份已知导航文档及显式未入库候选；其他结构用`--exclude 文件名`指定。
它仅检查本地文档链接、可识别总数及已有编号，不访问外网、不改文档、不识别所有Markdown插件语法。
默认分类不适用于目标库时先调整排除列表，不能把工具推断当作用户的正式选案决定。
